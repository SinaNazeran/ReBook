# تصاویر معرفی ری‌بوک

این پوشه همراه README در مخزن منتشر می‌شود. تصاویر محصول از اجرای محلی سایت گرفته شده‌اند؛ بنر یک ترکیب مستقل از نشان و زبان بصری پروژه است.

| فایل | محتوا |
| --- | --- |
| `banner.jpg` | بنر با نشان عطف کتاب، لاله‌زار و وزیرمتن، کاغذ روشن و هشت رنگ مجموعه |
| `home.jpg` | صفحهٔ اصلی دسکتاپ؛ تیتر و جلدها پس از بارگذاری کامل |
| `catalog.jpg` | فهرست دسکتاپ؛ دسته‌ها، فیلترها و اولین ردیف کتاب‌ها |
| `book.jpg` | جزئیات دیوان حافظ؛ وضعیت، یادداشت فروشنده و بخش خرید |
| `cart.jpg` | سبد مهمان با دیوان حافظ و شازده کوچولو، بدون ثبت سفارش |
| `mobile.jpg` | صفحهٔ جزئیات شازده کوچولو در عرض موبایل |

## به‌روزرسانی تصاویر

1. بک‌اند و فرانت‌اند را طبق README اجرا کنید و چند کتاب تأییدشده با جلد مناسب داشته باشید.
2. صفحات عمومی را با مرورگر مهمان باز کنید. برای تصویر سبد، دو کتاب اضافه کنید؛ نیازی به ورود، آدرس یا پرداخت نیست.
3. برای دسکتاپ از عرض ۱۴۴۰ و برای موبایل از عرض ۴۳۰ پیکسل استفاده کنید. کادر تصویر می‌تواند بر اساس محتوای صفحه تغییر کند.
4. پس از نمایش نهایی صفحه، پایان حرکت ورودی و بارگذاری فونت‌ها و همهٔ جلدها تصویر بگیرید. تصویر ذخیره‌شده را دوباره باز کنید؛ نمایش درست صفحه در مرورگر به‌تنهایی صحت فایل خروجی را تضمین نمی‌کند.
5. از ثبت منوی باز، نشانگر روی جلد، حالت loading یا اطلاعات شخصی در تصویر معرفی جلوگیری کنید.
6. فایل‌های JPEG را با همین نام‌ها جایگزین کنید تا لینک‌های نسبی README سالم بمانند. متن جایگزین تصاویر را متناسب با محتوای جدید تغییر دهید.

## منبع بنر

`banner-source.html` منبع قابل ویرایش بنر است. فونت‌ها از وابستگی‌های موجود فرانت‌اند خوانده می‌شوند؛ ابتدا در `frontend/` دستور `npm ci` را اجرا کنید. برای پیش‌نمایش، از ریشهٔ پروژه یک سرور فایل محلی اجرا کنید:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

نشانی `http://127.0.0.1:8765/docs/readme/banner-source.html` را باز کنید، پس از بارگذاری فونت‌ها از خود بنر در اندازهٔ ۱۴۴۰ × ۴۴۰ پیکسل خروجی بگیرید و `banner.jpg` را جایگزین کنید. README از تصویر نهایی استفاده می‌کند و برای نمایش در گیت‌هاب به فونت یا سرور محلی نیاز ندارد.

رنگ‌ها و نشان از `frontend/src/styles/theme.css` و `frontend/src/components/BrandMark.jsx` گرفته شده‌اند. در صورت تغییر هویت بصری سایت، منبع بنر و تصویر نهایی را با هم به‌روز کنید.
