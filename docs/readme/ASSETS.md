# تصاویر معرفی ری‌بوک

[README](../../README.md)

تصاویر از اجرای محلی سایت با محتوای نمونه و حساب ساختگی تهیه شده‌اند. هیچ پرداخت یا اطلاعات شخصی واقعی در آن‌ها نیست.

## تصاویر منتخب README

| فایل | محتوا |
| --- | --- |
| `banner.jpg` | بنر ۱۴۴۰×۵۶۰ با نشان رسمی، زمینهٔ شرابی و سه جلد واقعی |
| `home.jpg` | صفحهٔ اصلی در دسکتاپ |
| `catalog.jpg` | فهرست و فیلترهای کتاب‌ها در دسکتاپ |
| `sell.jpg` | آغاز فرم فروش و پیش‌نمایش آگهی در دسکتاپ |
| `mobile-catalog-cards.jpg` | کارت‌های کامل کتاب‌ها در موبایل |
| `mobile-book-info.jpg` | اطلاعات نسخه و نوار خرید در موبایل |

این پوشه شامل بنر و پنج تصویر محصولِ استفاده‌شده در README، منبع بنر و جلدهای وابسته به آن است. شش فایل `tech-*.svg` نشان‌های فناوری با رنگ‌های برند هستند؛ متن و نسخهٔ هر نشان باید با متن جایگزین آن در README هماهنگ بماند.

## به‌روزرسانی تصاویر

- سایت را با داده‌های نمونه اجرا کنید؛ فونت‌ها، تصاویر و حرکت ورودی پیش از ثبت کامل شوند.
- viewport دسکتاپ ۱۴۴۰×۱۰۰۰ و موبایل ۳۹۰×۸۴۴ پیکسل CSS است. ابعاد بومی فایل‌های منتخب دسکتاپ ۱۴۲۵×۹۹۰ و موبایل ۳۷۵×۸۱۱ پیکسل است؛ آن‌ها را برای تحمیل اندازه نکشید.
- قاب را طوری انتخاب کنید که عنوان‌ها زیر هدر پنهان نشوند و اطلاعات اصلی یا دکمهٔ خرید خوانا بمانند. برای معرفی فرم بلند، قاب منتخب کافی است.
- فایل JPEG اصلی مرورگر را نگه دارید؛ پیش از جایگزینی، تصویر را باز و متن جایگزین README را با آن هماهنگ کنید.
- در فرم فروش از اطلاعات نمونه استفاده کنید؛ برای تهیهٔ تصویر نیازی به ارسال آگهی نیست.

## منبع بنر

پس از نصب وابستگی‌های فرانت‌اند، از ریشهٔ پروژه `python -m http.server 8765 --bind 127.0.0.1` را اجرا و [منبع بنر](banner-source.html) را در نشانی `http://127.0.0.1:8765/docs/readme/banner-source.html` باز کنید. پس از بارگذاری فونت و جلدها، در نمای ۱۴۴۰×۵۶۰ خروجی بگیرید.

نشان از `frontend/public/brand/rebook-header-white.svg` با نسبت اصلی ۳۹۱:۱۲۶ بارگذاری می‌شود. `brand-*.webp` جلدهای بنر هستند؛ رنگ و برجستگی دکمه و نوار هشت‌رنگ از هدر سایت گرفته شده‌اند. [راهنمای برند](../branding.md).
