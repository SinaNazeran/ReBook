# تصاویر معرفی ری‌بوک

[گالری کامل](gallery.md) · [README](../../README.md)

تصاویر محصول از اجرای محلی سایت گرفته شده‌اند. صفحات حساب با کاربر `reader_demo` و دیتابیس موقت نمایش داده شده‌اند. هیچ سفارش واقعی برای تهیهٔ آن‌ها ثبت نشده است.

## فایل‌ها

- `banner.jpg`: بنر «جلد چاپی مدرن» با شرابی غالب، نام بزرگ ری‌بوک و سه جلد واقعی.
- `banner-source.html`: منبع قابل ویرایش بنر با فونت‌های موجود پروژه.
- `brand-*.webp`: جلدهای مورد استفاده در بنر، برگرفته از محتوای نمونهٔ سایت.
- تصاویر دسکتاپ و `mobile-*.jpg`: صفحات و قاب‌های ادامهٔ مسیر؛ فهرست و توضیح هر تصویر در گالری آمده است.
- `mobile.jpg`: قاب اول جزئیات کتاب؛ قاب‌های اطلاعات و شناسنامه در فایل‌های جدا هستند.

## تهیهٔ دوبارهٔ تصاویر

۱. سرورها را طبق README اجرا کنید و چند آگهی تأییدشده با جلد مناسب داشته باشید. برای حساب و معاملات از داده‌های نمونه استفاده کنید.

۲. برای دسکتاپ عرض ۱۴۴۰ و برای موبایل عرض ۳۹۰ و ارتفاع ۸۴۴ پیکسل را تنظیم کنید. پس از تغییر عرض، چیدمان نهایی و بارگذاری فونت‌ها و عکس‌ها را کنترل کنید.

۳. تصویر را تنها پس از پایان حرکت ورودی ثبت کنید. فایل خروجی را دوباره باز کنید؛ تصویر loading یا چیدمان دسکتاپ کوچک‌شده نباید به‌عنوان موبایل ذخیره شود.

۴. برای صفحه‌های بلند، با هم‌پوشانی اسکرول کنید و از هر بخش یک قاب مستقل بگیرید. تصویر بلند کل صفحه یا کوچک‌کردن اجباری محتوا جایگزین قاب خوانا نیست.

۵. برای سبد، کتاب اضافه کنید؛ نیازی به آدرس یا پرداخت نیست. فرم فروش می‌تواند برای نمایش پیش‌نمایش پر شود، بدون اینکه آگهی ثبت شود.

۶. فایل‌ها را با همان نام جایگزین کنید و متن جایگزین و توضیح گالری را با محتوای جدید هماهنگ نگه دارید. تصاویر منو یا فیلتر باز تنها وقتی ثبت شوند که همان قابلیت را معرفی می‌کنند.

## بنر

ابتدا در `frontend/` دستور `npm ci` را اجرا کنید. سپس از ریشهٔ پروژه:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

نشانی `http://127.0.0.1:8765/docs/readme/banner-source.html` را باز کنید. پس از بارگذاری فونت‌ها و سه جلد، از پوستر در نمای ۱۴۴۰ × ۵۶۰ خروجی بگیرید و `banner.jpg` را جایگزین کنید. نمایش تصویر نهایی در گیت‌هاب به سرور یا فونت محلی وابسته نیست.

رنگ‌ها و نشان با `frontend/src/styles/theme.css` و `frontend/src/components/BrandMark.jsx` هماهنگ‌اند. فونت تیتر لاله‌زار و فونت متن وزیرمتن است.
