# لوگوی ری‌بوک — نسخهٔ ۷.۱

لوگوی تأییدشده بدون قاب و بدون نقطهٔ «ی» است. اتصال سرکش و بدنهٔ «ک» و هندسهٔ پیکان در فایل‌های نهایی تثبیت شده‌اند. SVGها از مسیرهای برداری تشکیل شده‌اند و به فونت نصب‌شده وابسته نیستند.

## فایل‌های استفاده‌شده در سایت

| کاربرد | فایل در frontend/public |
|---|---|
| هدر تیره؛ بدون زیرنویس لاتین | `brand/rebook-header-white.svg` |
| فوتر تیره؛ نسخهٔ کامل با REBOOK | `brand/rebook-primary-white.svg` |
| نشان مستقل جلدهای بدون عکس | `brand/rebook-symbol-burgundy.svg` |
| فاویکون تطبیقی روشن/تیره | `favicon.svg` |
| جایگزین PNG برای تم تیره | `favicon-dark-32.png` |
| فاویکون سازگار با مرورگرهای قدیمی‌تر | `favicon.ico`، شامل ۱۶/۳۲/۴۸ پیکسل |
| آیکون Apple | `apple-touch-icon.png`، ۱۸۰×۱۸۰ |
| آیکون‌های manifest | `icon-192.png`، `icon-512.png` و `icon-maskable-512.png` |

`index.html` آیکون‌های مرورگر و manifest را معرفی می‌کند. نسخه‌های رنگی و خروجی‌های دیگر، بخشی از بستهٔ اصلی طراحی هستند و تا زمانی که در سایت استفاده نمی‌شوند در public قرار نمی‌گیرند.

## اندازه، نسبت و حاشیهٔ امن

- عرض لوگوی هدر در دسکتاپ ۱۶۰، زیر ۹۹۲ پیکسل ۱۴۰ و زیر ۳۶۰ پیکسل ۱۲۰ پیکسل است.
- عرض نسخهٔ کامل فوتر ۲۶۰ پیکسل است.
- ویژگی‌های ابعادی تصویر نسبت دقیق SVG را رزرو می‌کنند: ۳۹۱:۱۲۶ برای هدر و ۳۹۱:۱۵۰ برای فوتر. اندازهٔ نمایشی را CSS تعیین می‌کند؛ ارتفاع باید auto بماند.
- حاشیهٔ امن در خود فایل‌ها قرار دارد. فایل را نبرید و نسبت عرض و ارتفاع آن را تغییر ندهید.
- نشان maskable روی زمینهٔ کاملاً مات قرار دارد و طرح داخل دایرهٔ امن مرکزی، با شعاع ۴۰٪ عرض تصویر، حفظ شده است.

## رنگ و کاربرد

شرابی `#6E172C` و صورتی `#F6C2C6` رنگ‌های برند هستند. روی زمینهٔ هدر `#480217` و فوتر شرابی از نسخهٔ سفید استفاده می‌شود. رنگ زمینهٔ manifest برابر `#F5F5F2` است. نشان جلد با ماسک SVG و currentColor، رنگ متن جلد را می‌پذیرد تا روی مرکب مجموعه خوانا بماند.

## پیاده‌سازی و تعامل

`BrandLogo` تصویر تزئینی را در پیوند خانه قرار می‌دهد. هر دو پیوند هدر و فوتر نام دسترس‌پذیر «ری‌بوک — صفحهٔ اصلی» دارند؛ تصویر با alt خالی و aria-hidden از تکرار نام جلوگیری می‌کند. `BrandMark` نشان تزئینی روی جلد است.

- Hover روی اشاره‌گر دقیق: حرکت کل تصویر یک پیکسل به بالا، طی ۱۶۰ میلی‌ثانیه.
- فشردن: مقیاس ۰٫۹۹ طی ۱۰۰ میلی‌ثانیه؛ ناحیهٔ پیوند ثابت می‌ماند.
- فوکوس صفحه‌کلید: حلقهٔ سفید ۲ پیکسلی با فاصلهٔ ۴ پیکسل.
- تنظیم کاهش حرکت: تبدیل و transition تصویر حذف می‌شوند و بازخورد فشردن ثابت است.
- منوی باز موبایل حداکثر به اندازهٔ ارتفاع viewport است و در صفحه‌های کوتاه اسکرول داخلی دارد.

اندازه و فوکوس در `src/styles/app/navigation.css`، حرکت در `navigation-motion.css` و فضای لوگوی فوتر در `footer.css` تعریف شده‌اند. manifest همچنان display برابر browser دارد؛ این تغییر قابلیت نصب تازه‌ای ایجاد نمی‌کند.

برای بررسی تغییرات بعدی، lint و آزمون‌های موجود پروژه را اجرا کنید و هدر، فوتر، منوی باز، تم آیکون و تنظیم کاهش حرکت را بازبینی کنید. آزمون مرورگری با viewport موبایل جای آزمایش گوشی فیزیکی را نمی‌گیرد.
